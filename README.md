# Business Sales Performance Analytics

## Future Interns – Data Science & Analytics Internship
**Task 1: Business Sales Performance Analytics**

## Project Overview
This project focuses on analyzing business sales data to understand sales performance, identify trends, and generate meaningful business insights using Microsoft Power BI.

## Objectives
- Analyze overall sales and profit.
- Identify top-performing products.
- Understand sales distribution across categories.
- Compare sales performance across different regions.
- Analyze monthly sales trends.
- Create an interactive dashboard for business insights.

## Dataset
**Dataset Name:** Sample Superstore Dataset

The dataset contains sales transaction details, including:
- Order Date
- Product Name
- Category and Sub-Category
- Region, State and City
- Sales
- Quantity
- Discount
- Profit

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset

## Data Preparation
- Imported the dataset into Power BI.
- Checked for missing values and duplicate records.
- Verified column data types.
- Prepared the data for analysis and visualization.

## Dashboard Features
The interactive dashboard includes:

- Total Sales
- Total Profit
- Total Quantity
- Total Orders
- Monthly Sales Trend
- Top 10 Products by Sales
- Sales by Region
- Sales by Category
- Profit by Category

## Key Insights
- Technology recorded the highest sales among the three categories.
- The West region generated the highest sales.
- Technology contributed the highest profit.
- Furniture showed comparatively lower profitability.
- The dashboard provides an overview of business sales performance.
